# 🤖 AI Business Intelligence Dashboard

An AI-powered e-commerce analytics dashboard built with Python and Streamlit.

## 📌 Overview

This project provides an interactive business intelligence platform for analyzing e-commerce performance.

The dashboard combines historical data analysis, KPI monitoring, automated business insights, and predictive revenue forecasting.

## 🚀 Features

- 📊 Executive business dashboard
- 💰 Revenue analytics
- 🛒 Sales analytics
- 📢 Marketing analytics
- 🤖 Automated AI business insights
- 🔮 30-day revenue forecasting
- 📋 Interactive data explorer
- 📅 Custom date-range analysis
- 📈 Interactive Plotly visualizations
- 🌙 Professional black and blue UI

## 🧠 AI & Analytics

The project includes:

- KPI analysis
- Period-over-period comparison
- Rule-based business insights
- Linear Regression revenue forecasting
- Historical vs forecast analysis

## 🛠️ Technologies

- Python
- Streamlit
- Pandas
- Plotly
- Scikit-learn

    ▶️ How to Run

Clone the repository and install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
🔮 Forecasting

The forecasting module uses Linear Regression to estimate revenue for the next 30 days based on historical revenue patterns.

⚠️ Disclaimer

This project is an MVP business intelligence and predictive analytics system. Forecast accuracy depends on the quality and historical patterns of the available dataset.
